# Tkinter Registration Form

This project is a simple registration form built with Python and Tkinter.

## Features
- User registration form
- Validation for required fields
- Email format check
- Password length validation
- Password confirmation check
- Success and error message boxes

## Tech Stack
- Python
- Tkinter

## Run the Application

```bash
python registration_app.py
```

## Project Files
- `registration_app.py` - main application
- `README.md` - project documentation
